**CodeWitness 1.0.5** converts the three HDL-family adapters and records, as a test, what an adapter is allowed to
claim. Twelve of sixteen adapters now declare their tools once.

## What changed

- **Verilog, VHDL and Pascal** extend `AbstractLanguageAdapter` and declare their provider set once. Their
  `build`/`runTests`/`analyze` delegations and hand-written capability lists are gone.
- **A prediction from the previous release was wrong, and this one says so.** 1.0.4 warned that these three would end
  up with *smaller* capability sets than their hand-written lists. They do not: all three already declared exactly
  the eight phases they register — detection, build, tests, static analysis, mutation, property testing, generated
  tests and security, with no coverage and no dependency inventory — so the derivation produced the same set. The
  conversion is structural, not behavioural, and the honest record of that is better than a release note that takes
  credit for a change it did not make.
- **`AdapterCapabilityTest` is the new contract.** It asserts that every bundled adapter can inspect; that Verilog,
  VHDL and Pascal claim exactly those eight capabilities and neither coverage nor a dependency inventory (Icarus and
  GHDL export no coverage this tool reads, and an HDL design has no package manager); and that the adapters with no
  dependency analyzer are exactly Pascal, SQL, Verilog and VHDL. That last assertion caught its own author: the list
  is four because SQL loads a schema rather than resolving packages.

## Verified for this release

- Full reactor test suite: **1742 tests, 0 failures** across all 22 modules (up from 1739).
- The three converted adapters' own tests — build, tests, mutation, scenario generation for Verilog, VHDL and Pascal —
  pass unchanged, and their capability sets are pinned by the new test rather than by a comment.

## Compatibility

- Internal: no report format, verdict, exit code, CLI or configuration change. The capability sets of the three
  converted adapters are identical before and after.
