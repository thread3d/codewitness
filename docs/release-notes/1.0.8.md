**CodeWitness 1.0.8** splits the README. What was a 2,458-line document is now a landing page and eleven reference
documents in `docs/`, so the front page is something a person can read in one sitting.

## What changed

- **The README is a landing page** (396 lines): what the tool is, a worked quick start, what it is not, the five
  verdicts, the command line, the self-issue log, the MCP server, requirements, versioning, the backlog, how to
  release, how to build and test, and a table pointing at everything else.
- **The reference material moved into `docs/`**, and it was *moved* rather than rewritten: each section was extracted
  verbatim under its own title, so the change can be reviewed as a diff rather than trusted as a rewrite.

  | New document | Lines |
  | --- | --- |
  | `docs/languages.md` | 225 |
  | `docs/scenarios.md` | 374 |
  | `docs/configuration.md` | 67 |
  | `docs/findings-in-ci.md` | 37 |
  | `docs/reports.md` | 53 |
  | `docs/project-layout.md` | 90 |
  | `docs/status.md` | 1,186 |

  The README's security section was appended to the existing `docs/security.md` rather than becoming a second
  security document: two accounts of the same execution model is how they start to disagree.
- **Two things were fixed rather than only moved.** Sibling links inside the moved documents still used repo-root
  paths (`docs/writing-scenarios.md` from inside `docs/`), which would have been dead links; a link check over every
  relative link in the README and `docs/` now reports zero unresolved. And the self-check's `CWR-006` cited
  `README "Configuration"`, which no longer exists — it now cites `docs/configuration.md`.
- **The split is verified by content, not by line counts**: distinctive phrases from each moved section are asserted to
  be present in their new file and absent from the README, and every heading from the original appears exactly once
  across the two.

## Verified for this release

- Full reactor test suite: **1746 tests, 0 failures** across all 22 modules.
- Zero broken relative links across `README.md` and `docs/*.md`.
- The self-check's requirements still parse and still name their source documents correctly.

## Compatibility

- Documentation only: no code, report format, verdict, exit code, CLI or configuration change.
