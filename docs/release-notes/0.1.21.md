**CodeWitness 0.1.21** completes the phase extraction: all seven phases of the verification pipeline are now
methods, and `verify()` has lost more than a third of its body.

## What changed

- **`testsPhase`, `coveragePhase` and `mutationPhase`** complete the set begun in 0.1.16. `verify()` is now **433
  lines, down from 670**, and contains **no inline phase body**: it schedules seven phases, each of which takes the
  `RunScope` and what it needs to analyse.
- Two of these carried details that are easy to destroy in a move, and both were moved verbatim: the tests
  evidence records **the command that produced the result** rather than the build command (which compiles without
  running tests, so recording it would describe an invocation that cannot have yielded the result), and it keeps
  the runner's note, because that note is how a runner says what it parsed is not the whole story. Coverage keeps
  the same empty-selection guard as dependencies: an empty selection can mean "no provider" or "nothing built",
  and reporting the first when it is the second states a configuration fact that is false.
- Mutation is the phase that reports how strong the tests are rather than whether the code is correct, which is
  why a surviving mutant is `INCONCLUSIVE` and a limitation on the requirement rather than a `REFUTES`. That
  distinction is now visible in a method with a javadoc saying so, instead of a nested ternary inside a 670-line
  body.

## Verified for this release

- Full reactor test suite: **1729 tests, 0 failures** across all 22 modules, unchanged from before the change.
- The three phases are covered by the engine tests that assert what each records — evidence types, artefact
  metadata, per-language merging, the empty-selection explanations, and mutation's treatment of a surviving
  mutant — plus every adapter suite that drives its own provider through them.

## Compatibility

- No behaviour change: no report format, verdict, exit code, CLI or configuration difference. This release moves
  code and says where it went.
