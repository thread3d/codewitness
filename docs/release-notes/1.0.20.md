**CodeWitness 1.0.20** passes self-verification with all ground rules verified.

## What changed

- **Self-check verification** — CodeWitness verified itself against all seven ground rules (CWR-001 through CWR-007) with `VERIFIED` verdicts. The self-check ran the full verification pipeline (build, tests, static analysis, dependency scan, coverage) without mutation testing, all against the project's own codebase.

- **1,760 tests executed, 0 failures** — The existing test suite remains fully green.

- **71.2% line coverage** — Measured across the full codebase.

## What this release confirms

This release confirms that CodeWitness is self-consistent:

- Ground rules are documented in `selfcheck/requirements.yaml` and enforced by the engine
- The verification pipeline runs end-to-end against CodeWitness itself
- All verdicts are `VERIFIED` with appropriate evidence chains

## Compatibility

- No breaking changes
- All existing adapters, CLI commands, and report formats unchanged

## Notes

The self-check is now a documented verification step that can be replayed on any machine with the required toolchain. Run it with:

```bash
export JAVA_HOME=/path/to/jdk-25
export HOME=/path/to/workspace
export JAVA_TOOL_OPTIONS=-Dmaven.repo.local=/path/to/workspace/.m2/repository
./codewitness verify . --requirements selfcheck/requirements.yaml --config selfcheck/codewitness.yaml --no-mutation --max-duration 30m
```
